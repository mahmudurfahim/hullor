# HULLOR — ই-কমার্স ওয়েবসাইট

সম্পূর্ণ স্ট্যাটিক (HTML/CSS/JavaScript) ই-কমার্স ওয়েবসাইট, বাংলা ভাষায়, Vercel-এ ডিপ্লয়মেন্টের জন্য প্রস্তুত। কোনো npm/build স্টেপ লাগে না।

## ফোল্ডার স্ট্রাকচার

```
hullor/
├── index.html               → হোম পেজ (হিরো স্লাইডার, ফিচার্ড প্রোডাক্ট, আমাদের সম্পর্কে)
├── shop/index.html          → শপ পেজ, URL হবে /shop (কোনো .html দেখাবে না)
├── css/style.css            → সম্পূর্ণ ডিজাইন
├── js/products.js           → পণ্যের তালিকা (এখানেই নতুন পণ্য যোগ করবেন)
├── js/main.js                → কার্ট + চেকআউট + স্লাইডার লজিক (এখানে Apps Script URL ও WhatsApp নম্বর বসাতে হবে)
├── images/                   → সব প্রোডাক্ট ছবি (এখন সব ডেমো ছবি)
├── apps-script/Code.gs       → Google Sheet-এ অর্ডার সেভ করার স্ক্রিপ্ট
└── vercel.json
```

**URL নিয়ে একটা কথা:** শপ পেজটি `shop.html` না রেখে `shop/index.html` হিসেবে রাখা হয়েছে, তাই Vercel-এ এটি স্বয়ংক্রিয়ভাবে `yourdomain.com/shop` (কোনো `.html` ছাড়া) হিসেবে খুলবে। `vercel.json`-এ `cleanUrls: true` থাকায় এটি যেকোনো স্ট্যাটিক হোস্টেও একইভাবে কাজ করবে।

## ধাপ ১: আসল প্রোডাক্ট ছবি বসানো

`images/` ফোল্ডারে বর্তমানে ডেমো ছবি আছে (যেমন `shirt1-demo.jpg`, `punjabi2-demo.jpg`)। আপনার আসল ছবি **একই নামে** এই ফোল্ডারে রিপ্লেস করে দিলেই ওয়েবসাইটে চলে আসবে — কোনো কোড পরিবর্তনের দরকার নেই।

উদাহরণ: `shirt1-demo.jpg` এর জায়গায় আপনার শার্টের আসল ছবি একই নামে (`shirt1-demo.jpg`) আপলোড করুন। ছবির সাইজ ৪:৫ (পোর্ট্রেট, যেমন 900×1125px) হলে সবচেয়ে ভালো দেখাবে।

নতুন পণ্য যোগ করতে চাইলে `js/products.js` ফাইলে নতুন লাইন যোগ করুন — প্রতিটি পণ্যের নাম, কোড, দাম, ক্যাটাগরি, সাইজ ও ছবির নাম উল্লেখ আছে সেখানে, প্যাটার্ন অনুসরণ করলেই চলবে। কোনো পণ্য হোম পেজের "ফিচার্ড প্রোডাক্ট" অংশে দেখাতে চাইলে সেই প্রোডাক্টে `featured: true` যোগ করুন।

## ধাপ ২: হোয়াটসঅ্যাপ নম্বর বসানো

সাইটের প্রধান "অর্ডার করুন" বাটনগুলো এখন হোয়াটসঅ্যাপে নিয়ে যায় (কল করার বদলে)। `js/main.js` ফাইলের উপরের দিকে এই লাইনে আপনার নম্বর বসান (৮৮ কান্ট্রি কোডসহ, শুরুর ০ ছাড়া):

```javascript
const WHATSAPP_NUMBER = "8801863709122";
```

এই একটা জায়গা বদলালেই নেভিগেশন আইকন, হিরো সেকশনের বাটন, ফুটার এবং অর্ডার কনফার্মেশন — সব জায়গায় সঠিক নম্বর ব্যবহার হবে।

---

## ধাপ ৩: অর্ডার সংগ্রহের জন্য Google Sheet + Apps Script সেটআপ

1. একটি নতুন **Google Sheet** তৈরি করুন (sheets.new) — নাম দিন যেমন "Hullor Orders"।
2. উপরের মেনু থেকে **Extensions → Apps Script** এ ক্লিক করুন।
3. যা কোড আগে থেকে থাকবে তা মুছে ফেলুন এবং এই প্রজেক্টের `apps-script/Code.gs` ফাইলের সম্পূর্ণ কোড কপি করে পেস্ট করুন।
4. উপরে **Deploy → New deployment** এ ক্লিক করুন।
5. Gear আইকনে ক্লিক করে টাইপ হিসেবে **Web app** বেছে নিন।
6. সেটিংস এভাবে দিন:
   - **Execute as:** Me (আপনার অ্যাকাউন্ট)
   - **Who has access:** Anyone
7. **Deploy** বাটনে ক্লিক করুন। প্রথমবার অনুমতি (permission) চাইবে — অনুমতি দিন (Advanced → Go to project (unsafe) → Allow)।
8. ডিপ্লয়মেন্ট শেষে একটি **Web app URL** পাবেন, দেখতে এরকম:
   `https://script.google.com/macros/s/AKfycb.../exec`
9. এই URL কপি করে `js/main.js` ফাইলের একদম উপরের দিকে থাকা এই লাইনে বসান:

   ```javascript
   const APPS_SCRIPT_URL = "এখানে আপনার URL বসান";
   ```

এখন থেকে ওয়েবসাইটে আসা প্রতিটি অর্ডার আপনার Google Sheet-এর "Orders" ট্যাবে স্বয়ংক্রিয়ভাবে যোগ হবে (নাম, ফোন, ঠিকানা, পণ্যের তালিকা, মোট টাকা সহ)। কাস্টমার একই সাথে চাইলে "হোয়াটসঅ্যাপে অর্ডার কনফার্ম করুন" বাটনে চাপ দিয়ে আপনাকে সরাসরি হোয়াটসঅ্যাপেও অর্ডারের বিস্তারিত পাঠাতে পারবে।

> ⚠️ কোড পরিবর্তন করার পর ভবিষ্যতে যদি Code.gs আপডেট করেন, তাহলে আবার **Deploy → Manage deployments → Edit → New version** করে ডিপ্লয় করতে হবে।

## ধাপ ৪: ফোন নম্বর ও দাম আপডেট (প্রয়োজনে)

- কল করার ফোন নম্বর (support-এর জন্য) `018637-09122` লিখে খুঁজলে পাবেন — Find & Replace ব্যবহার করুন।
- পণ্যের দাম, নাম, ছাড় (discount), ফিচার্ড স্ট্যাটাস — সবকিছু `js/products.js` ফাইলে পরিবর্তনযোগ্য।
- হিরো স্লাইডারের ৩টি ছবি ও টাইটেল `js/main.js` ফাইলের `HERO_SLIDES` অংশে পরিবর্তনযোগ্য।

## ধাপ ৫: GitHub-এ পুশ ও Vercel-এ ডিপ্লয়

```bash
git init
git add .
git commit -m "Hullor ecommerce website"
git branch -M main
git remote add origin <আপনার GitHub রিপোজিটরি URL>
git push -u origin main
```

তারপর [vercel.com](https://vercel.com) এ গিয়ে:
1. **Add New → Project**
2. আপনার GitHub রিপোজিটরি সিলেক্ট করুন
3. **Framework Preset:** Other (কারণ এটি প্লেইন HTML সাইট, কোনো বিল্ড কমান্ড লাগবে না)
4. **Deploy** এ ক্লিক করুন

কয়েক সেকেন্ডেই আপনার সাইট লাইভ হয়ে যাবে — হোম `yourdomain.com` এবং শপ পেজ `yourdomain.com/shop`।

## কার্ট সম্পর্কে একটি নোট

কার্ট এখন ব্রাউজারের `localStorage`-এ সেভ থাকে — অর্থাৎ হোম পেজ থেকে পণ্য কার্টে যোগ করে শপ পেজে গেলেও, বা পেজ রিফ্রেশ করলেও কার্টের পণ্য থেকে যাবে। কাস্টমার চেকআউট সম্পন্ন করলে বা কার্ট খালি করলে তবেই এটি মুছে যাবে।

## যা যা ফিচার আছে

- সম্পূর্ণ বাংলা ভাষার ওয়েবসাইট (UI + কন্টেন্ট), হোম ও শপ — দুটি আলাদা পেজ (clean URL: `/shop`)
- হোম পেজে ৩-ছবির অটো-স্লাইডিং হিরো স্লাইডার (ডট নেভিগেশনসহ)
- হোম পেজে বাছাই করা "ফিচার্ড প্রোডাক্ট", শপ পেজে সম্পূর্ণ ৭ ক্যাটাগরির কালেকশন (ক্যাটাগরি ফিল্টারসহ)
- "আমাদের সম্পর্কে" সেকশন
- প্রতিটি পণ্যের নিজস্ব প্রোডাক্ট কোড (যেমন HL-SHT-01)
- সাইজ সিলেকশনসহ কার্ট সিস্টেম, localStorage-এ পার্সিস্ট করে (পেজ পরিবর্তনেও কার্ট থাকে)
- সারা বাংলাদেশে ফ্রি ডেলিভারি, শুধু ক্যাশ অন ডেলিভারি
- হোয়াটসঅ্যাপে সরাসরি অর্ডার করার বাটন (নেভিগেশন, হিরো, ফুটার, অর্ডার কনফার্মেশন — সব জায়গায়)
- চেকআউট ফর্ম ভ্যালিডেশনসহ (নাম, ফোন নম্বর, জেলা, ঠিকানা)
- Google Sheet-এ সরাসরি অর্ডার সংরক্ষণ (Apps Script দিয়ে)
- মোবাইল-ফ্রেন্ডলি রেসপন্সিভ ডিজাইন
- Vercel-এ জিরো-কনফিগ ডিপ্লয়মেন্ট, ক্লিন URL (কোনো .html দেখাবে না)
